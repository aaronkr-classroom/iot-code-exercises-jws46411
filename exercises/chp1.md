# chp1 연습문제

1.Q1 *
  - (a) 디바이스의 센서와 액추에이터의 역할을 비교하여 설명하세요.
     - 센서는 온도, 습도 등 외부 환경 정보를 감지하여 데이터를 수집하는 장치이며,
       액추에이터는 해당 데이터를 기반으로 모터나 LED와 같은 물리적 동작을 수행하는 장치이다. 따라서 센서는 입력 장치이고 액추에이터는 출력 장치이다.
  
  - (b) 디바이스와 대시보드에서 동일한 프로그래밍 언어를 사용하지 않는 이유를 설명하세요.
    - 디바이스는 자원이 제한된 마이크로컨트롤러 환경에서 동작하고, 대시보드는 웹/서버 환경에서 동작하므로 요구되는 기능과 환경이 다르다.
      따라서 효율성과 목적에 맞는 서로 다른 프로그래밍 언어를 사용한다.
      
  - (c) 브로커와 같은 정보 전달 전담 서버의 이점을 설명하세요.
     - 브로커는 디바이스 간 데이터를 중개하여 직접 연결을 줄이고 시스템 구조를 단순하게 만든다.
       또한 중앙에서 데이터를 관리할 수 있어 확장성과 안정성이 향상된다.

2. Q2
  - (a) Mosquitto와 Node-RED를 별도 서버에 설치할 경우의 이점을 설명하세요.
  - Mosquitto와 Node-RED를 별도 서버에 설치하면 부하를 분산시켜 성능이 향상되고, 한쪽 장애가 전체 시스템에 미치는 영향을 줄일 수 있다.
    또한 각각 독립적으로 관리와 확장이 가능하다.
    
  - (b) Mosquitto와 Node-RED를 운영하기 위한 적절한 컴퓨팅 환경을 기술하세요.
     - Mosquitto와 Node-RED는 PC, 리눅스 서버 또는 라즈베리 파이와 같은 환경에서 운영할 수 있다.
       특히 라즈베리 파이는 저전력으로 서버 운영이 가능하여 IoT 환경에 적합하다.
       
  - (3) Mosquitto와 Node-RED에 대해 설명하고 실행에 적합한 컴퓨팅 환경을 제시하시오. *
